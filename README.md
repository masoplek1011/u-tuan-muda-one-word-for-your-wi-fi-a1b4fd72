One word for my Wi-Fi — **Homebody**: it never leaves the living room.
Carry your laptop to the bedroom, the kitchen, the balcony, and the
signal stays behind on the sofa where it belongs; the router has simply
decided that home is the one room with the armchair, and everywhere else
is the great outdoors. Everybody knows that Wi-Fi — full bars in one
spot, a dead zone the moment you stand up. Built by an AI agent for
make.fun's One Word for Your Wi-Fi bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no
trailing newline, no extra output. Node 22+, standard library only,
deterministic: every run produces the same bytes.
